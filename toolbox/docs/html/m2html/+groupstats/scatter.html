scatter

PURPOSE

SCATTER Scatter chart categorical table data.

SYNOPSIS

function varargout = scatter(tbl, xdatavar, ydatavar, cgroupvar,sgroupvar, opts, props)

DESCRIPTION 

SCATTER Scatter chart categorical table data.

  H = SCATTER(TBL, XDATAVAR, YDATAVAR, CGROUPVAR)
  H = SCATTER(TBL, XDATAVAR, YDATAVAR, CGROUPVAR, SGROUPVAR)
  [H, L, AX] = SCATTER(_)
  [___] = SCATTER(_, Name = Value)

 Description
  H = SCATTER(TBL, XDATAVAR, YDATAVAR, CGROUPVAR) plots TBL.(YDATAVAR)
  against TBL.(XDATAVAR), coloring each point by its CGROUPVAR member.

  H = SCATTER(_, SGROUPVAR) also varies the marker symbol and size by
  SGROUPVAR member, so one chart shows two groupings at once.

  [H, L, AX] = SCATTER(_) also returns the legend and the axes. H is a
  matrix with one row per color group and one column per size group.

 Name-value arguments
  CGroupMembers    Members of CGROUPVAR to keep. Rows outside them go.
  SGroupMembers    Members of SGROUPVAR to keep.
  RowSelectVar     Name of a variable used only to select rows.
  RowSelectMembers Members of RowSelectVar to keep.
  MergeGroupMembers A cell array of string vectors. Each cell names the
                   CGROUPVAR members to pool into one color group,
                   matching groupstats.histogram. A bare string vector
                   is one merge group. The merged group's label joins
                   the member names with " and ", and it takes the
                   position of its first member in the current category
                   order. CGroupMembers reads original names; the
                   legend reads post-merge names.
  SortGroup        Which grouping the legend order follows, "cgroupvar"
                   or "sgroupvar". Inert until SortBy is set.
  SortVar          Which data variable the legend order sorts on,
                   "xdatavar" or "ydatavar". Inert until SortBy is set.
  SortBy           "ascend", "descend", or "none" (default). "none"
                   keeps the legend in the group order. The direction
                   sorts the legend by the group mean of SortVar within
                   the SortGroup groups. So SortGroup picks which
                   grouping is sorted, SortVar picks which data
                   variable computes the statistic, and SortBy picks
                   the direction. The cats charts sort xgroupvar only,
                   so they have no SortGroup; their SortGroupMembers
                   picks the color-group members that enter the
                   statistic.
  CGroupOrder      A partial order of CGROUPVAR members. Named members
                   come first; the rest keep their order. Reorders the
                   draw and legend order and overrides SortBy.
  SGroupOrder      A partial order of SGROUPVAR members, the same way.
  Parent           Axes to plot into. The default is gca, so repeated
                   calls reuse the current axes rather than opening a
                   figure each time.
  Legend           "on" or "off".
  LegendString     Replacement legend entries. The default is the group
                   member names. LegendString(i) names the i-th
                   CGROUPVAR member in category order after member
                   filtering and merging, followed by one entry per
                   SGROUPVAR member when there are two or more.
                   CGroupOrder, SGroupOrder, and SortBy move the entries
                   with the groups, so an entry stays on its member. A
                   list that does not cover every entry is ignored and
                   the member names stand.
  LegendOrientation "vertical" or "horizontal".

  Any Line property may also be passed by name. gscatter draws the
  points as Line objects, so H holds Line handles and takes Line
  properties such as MarkerSize, not Scatter properties such as
  SizeData.

 Example
  data = groupstats.test.generateTestData('groupsummary');
  h = groupstats.scatter(data.tbl, "Value", "Other", "Grp");
  h = groupstats.scatter(data.tbl, "Value", "Other", "Grp", "Sub", ...
     SortVar = "ydatavar", SortBy = "descend", Legend = "off");

 Categorical data variables
  A categorical XDATAVAR or YDATAVAR whose categories are numbers is
  converted to those numbers. One whose categories are names is drawn
  by category ranking, with the categories as the tick labels, so an
  ordinal variable keeps its order on the axis and SortBy sorts the
  legend by that ranking.

 Positional order
  scatter charts two continuous data variables in the built-in
  scatter(x, y) order, so xdatavar comes before ydatavar. The cats
  charts put ydatavar second because their second axis is a grouping,
  not a data variable; there is no xgroupvar here to reconcile to.
  cgroupvar is required. This order is deliberate.

 Dependencies
  These matfunclib files ship inside the package, in private/:

   defaultcolors, defaultmarkers (libplot)
   dealout (functools)

 See also: boxchartcats, barchartcats, gscatter,
 groupstats.namelists.sortorder

0419    cleg = gobjects(numel(CGrps), 1);
0420    sleg = gobjects(numel(SGrps), 1);
0421 
0422    hold on;
0423    for n = 1:numel(CGrps)
0424       cleg(n) = patch(nan, nan, colors(n, :), 'EdgeColor', 'none');
0425       for m = 1:numel(SGrps)
0426          sleg(m) = plot(nan, nan, 'Marker', symbols{m}, 'MarkerSize', sizes(m), ...
0427             'LineStyle', 'none', 'MarkerFaceColor', 'none', ...
0428             'MarkerEdgeColor', 'k');
0429       end
0430    end
0431    hold off;
0432 end

0435 function L = groupLegend(cleg, sleg, CGrps, SGrps, legendnames, opts)
0436 
0437    % Return an empty handle rather than no value, so a caller that asks for
0438    % the legend output gets something it can test.
0439    if opts.Legend == "off"
0440       L = gobjects(0);
0441       return
0442    end
0443 
0444    % LegendString replaces the group member names. It must cover every entry,
0445    % so a short list falls back to the names rather than mislabeling them.
0446    % Each displayed member is looked up in the category-order name list,
0447    % color names in the first block and symbol names in the second, so a
0448    % reordered or sorted legend keeps every entry on its member.
0449    centries = string(CGrps(:));
0450    sentries = string(SGrps(:));
0451    if numel(opts.LegendString) == numel(legendnames)
0452       [~, cloc] = ismember(centries, legendnames(1:numel(centries)));
0453       [~, sloc] = ismember(sentries, legendnames(numel(centries) + 1:end));
0454       centries = opts.LegendString(cloc);
0455       sentries = opts.LegendString(numel(centries) + sloc);
0456    end
0457    entries = [centries; sentries];
0458 
0459    % One combined legend holds the color entries then the symbol entries.
0460    L = legend(opts.Parent, [cleg(:); sleg(:)], entries, ...
0461       'Location', 'eastoutside', ...
0462       'Orientation', opts.LegendOrientation);
0463 end
