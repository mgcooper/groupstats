boxchartcats

PURPOSE

BOXCHARTCATS Box chart by groups along x-axis and by color within groups.

SYNOPSIS

function varargout = boxchartcats(tbl, ydatavar, xgroupvar, cgroupvar, opts, props)

DESCRIPTION 

BOXCHARTCATS Box chart by groups along x-axis and by color within groups.

 Description

 This function creates a box chart of the data grouped by categories.

 Syntax

 h = boxchartcats(tbl, ydatavar) creates a box chart, or box plot, for column
 DATAVAR in table tbl. If tbl.(DATAVAR) is a vector, then boxchart creates a
 single box chart. In this mode, BOXCHARTCATS behaves exactly like
 BOXCHART(ydata) where ydata = tbl.(ydatavar).

 h = boxchartcats(tbl, ydatavar, xgroupvar) groups the data in the vector
 tbl.(DATAVAR) according to the unique values in tbl.(xgroupvar) and plots each
 group of data as a separate box chart. xgroupdata determines the position
 of each box chart along the x-axis. ydata must be a vector, and xgroupdata
 must have the same length as ydata.

 h = boxchartcats(tbl, ydatavar, xgroupvar, cgroupvar, xgroupuse, cgroupuse)
 uses color to differentiate between box charts. The software groups the
 data in the vector ydata according to the unique value combinations in
 xgroupdata (if specified) and cgroupdata, and plots each group of data as a
 separate box chart. The vector cgroupdata then determines the color of each
 box chart. ydata must be a vector, and cgroupdata must have the same length
 as ydata. Specify the 'GroupByColor' name-value pair argument after any of
 the input argument combinations in the previous syntaxes.

 h = boxchartcats(_, Name, Value) specifies additional chart options using
 one or more name-value pair arguments. For example, you can compare sample
 medians using notches by specifying 'Notch','on'. Specify the name-value
 pair arguments after all other input arguments. For a list of properties,
 see BoxChart Properties.

 Input Arguments

 tbl: A table containing the data to be plotted.
 ydatavar: The name of the variable in the table tbl that contains the data
 values for the box chart.
 xgroupvar: The name of the categorical variable in the table tbl used to
 define groups along the x-axis.
 cgroupvar: The name of the categorical variable in the table tbl used to
 define groups for the colors of the boxes.
 xgroupuse: A cell array of categories to be used for the x-axis grouping.
 cgroupuse: A cell array of categories to be used for the color grouping.
 varargin: Additional optional arguments for the boxchart function.

 MergeGroupMembers: A cell array of string vectors. Each cell names the
 color-group members to pool into one box group, matching
 groupstats.histogram. A bare string vector is one merge group. The
 merged group's label joins the member names with " and ", and it takes
 the position of its first member in the current category order.
 CGroupMembers reads original names; CGroupOrder and the legend read
 post-merge names.

 Parent: The axes to draw into. The default is gca, so repeated calls
 reuse the current axes. The boxes, the mean symbols, the shading, the
 legend, and the axis formatting all go into this axes, and the
 current axes is not touched when another one is named.

 LegendString: Replacement legend entries, one per color-group member.
 LegendString(i) names the i-th member in category order after member
 filtering and merging. CGroupOrder permutes the entries with the
 series, so an entry stays on its member. SortBy orders the x-groups
 and leaves the legend as it is.

 ShadeGroups: Shade alternating x-tick groups to tell one group of
 boxes from the next. Defaults to true when cgroupvar is given and
 false otherwise, because the shading marks a boundary between
 colored boxes that a single-series chart does not have. Pass
 ShadeGroups=true to shade a single-series chart anyway.

 Note: a box holding one observation collapses to a zero-height box
 with zero-length whiskers, so the mean symbol is its only visible
 mark. The chart warns when every box is like that.

 Output Arguments

 H: A handle to the created box chart.
 L: The legend, or an empty graphics placeholder when the legend could
    not be created.
 AX: The axes the chart was drawn into.

 Example

 Plot the peak variable of the fixture table, grouped along the x-axis
 by month and by color within each group by scenario.

  data = groupstats.test.generateTestData('info');
  h = groupstats.boxchartcats(data.Info, "peak", "month", "scenario");

 Restrict the groups to named members. XGroupMembers and CGroupMembers are
 name-value arguments, not positional ones.

  h = groupstats.boxchartcats(data.Info, "peak", "month", "scenario", ...
     XGroupMembers = ["Jan", "Feb", "Mar"], ...
     CGroupMembers = data.scenarios(1:2));

 Sort the x-groups by their group mean and pass BoxChart properties
 through:

  h = groupstats.boxchartcats(data.Info, "peak", "month", "scenario", ...
     SortBy = "ascend", Notch = "on", MarkerStyle = "none");

 Sorting

 SortBy orders the x-groups by their group mean, "ascend" or "descend".
 The sorted grouping is always xgroupvar. SortGroupMembers names the
 cgroupvar members whose rows enter each x-group's mean; omitted, or
 string.empty(), it uses every row. It needs cgroupvar, and each name
 must be one of its members (post-merge names after a merge). An x-group with no
 rows in the named members sorts last. XGroupOrder names the order
 directly and takes precedence over SortBy.

 Dependencies

 These come from matfunclib and must be on the path:

  defaultcolors (libplot)      colors the mean symbols like the boxes
  makevalidvarnames (libtable) builds the y-axis label
  naninterp1 (libstats)        fills gaps in the group shading bounds
  dealout (functools)          splits the outputs

 See also: reordergroups, reordercats, boxchart,
 groupstats.barchartcats, groupstats.namelists.sortorder

0402    if numel(opts.LegendString) == numel(members)
0403       opts.LegendString = opts.LegendString(idx);
0404    end
0405 end

0407 function XData = reorderGroups(opts, XData, YData, CData, sortmembers)
0408    %REORDERGROUPS Reorder the x-axis (tick) groups.
0409    %
0410    % An explicit XGroupOrder wins. Otherwise SortBy orders the x-groups by
0411    % their group mean over the rows SortGroupMembers selects. SORTMEMBERS
0412    % is true when the caller named members.
0413 
0414    if opts.XGroupOrder == "none"
0415       % Sort the x-groups by their group mean. YData here is the raw column,
0416       % not a summary matrix as in barchartcats, so the mean per x-group comes
0417       % from groupsummary rather than from a column mean.
0418       switch opts.SortBy
0419          case {"ascend", "descend"}
0420             members = string(categories(removecats(XData)));
0421 
0422             % Keep the rows of the named color-group members. The names
0423             % were checked against the members above.
0424             rows = true(size(YData));
0425             if sortmembers
0426                rows = ismember(string(CData), opts.SortGroupMembers);
0427             end
0428 
0429             % An x-group with no selected rows is absent from the summary,
0430             % so place each mean in its member's slot and leave the rest
0431             % NaN, which sort puts last.
0432             [groupmean, found] = groupsummary(YData(rows), XData(rows), ...
0433                "mean");
0434             stat = nan(size(members));
0435             [~, loc] = ismember(string(found), members);
0436             stat(loc) = groupmean;
0437 
0438             [~, idx] = sort(stat, opts.SortBy, 'MissingPlacement', 'last');
0439             XData = reordercats(XData, members(idx));
0440          otherwise
0441             % "none" leaves the category order as it is.
0442       end
0443    else
0444       % A partial order names some x-groups and leaves the rest behind
0445       % them, the way CGroupOrder does.
0446       members = string(categories(removecats(XData)));
0447       Locb = reordergroupmembers(opts.XGroupOrder, members, ...
0448          "boxchartcats", "XGroupOrder");
0449 
0450       % reordercats changes the display order and leaves the rows where
0451       % they are, so XData and YData stay paired row by row.
0452       XData = reordercats(XData, members(Locb));
0453    end
0454 end

0489 % Translation between boxchart and groupsummary
0490 %  boxchart    groupsummary(tbl,...)     groupsummary(A,...)
0491 % ----------  --------------------     -------------------
0492 % xgroupdata   groupvars{1} (varname)  groupvars(:,1) (column vector)
0493 % cgroupdata   groupvars{2} (varname)  groupvars(:,2) (column vector)
0494 % ydata        datavars     (varname)  A              (column vector)
0495 % N/A          method
0496 % N/A          groupbins = actual bin edges or method, for both tbl and A syntax
0497 function [mumat, medmat, xlocs] = boxchartstats(H, XData, YData, CData)
0498 
0499    % Import each package member this local function requires.
0500    import groupstats.boxchartxdata
0501 
0502    % Get the x-coordinate of each boxchart center
0503    [xlocs] = boxchartxdata(H);
0504 
0505    % Summarize over both groupings. A cell grouping spec keeps the two apart.
0506    % Concatenating them as [XData CData] fails when one is an ordinal
0507    % categorical and the other is not, which the ordinary two-group call is.
0508    [mu, uv] = groupsummary(YData, {XData, CData}, "mean");
0509    med = groupsummary(YData, {XData, CData}, "median");
0510 
0511    % Place each summarized pair in its own slot. xlocs holds one row
0512    % per color group and one column per x-tick. A combination with no rows is
0513    % absent from uv, so it stays NaN here rather than shifting every later
0514    % value onto the wrong box.
0515    xmembers = groupmemberlist(XData);
0516    cmembers = groupmemberlist(CData);
0517    [~, ix] = ismember(string(uv{1}), string(xmembers));
0518    [~, ic] = ismember(string(uv{2}), string(cmembers));
0519 
0520    mumat = nan(size(xlocs));
0521    medmat = nan(size(xlocs));
0522    keep = ix > 0 & ic > 0;
0523    slot = sub2ind(size(xlocs), ic(keep), ix(keep));
0524    mumat(slot) = mu(keep);
0525    medmat(slot) = med(keep);
0526 end

0528 function members = groupmemberlist(data)
0529    %GROUPMEMBERLIST Ordered members of a grouping vector, as boxchart draws it.
0530    %
0531    % boxchart lays out its ticks and its color series in category order for a
0532    % categorical. CData is logical when no color group was named, and unique
0533    % returns those in the same sorted order boxchart uses.
0534 
0535    if iscategorical(data)
0536       members = categories(removecats(data));
0537    else
0538       members = unique(data);
0539    end
0540 end

0542 function shadeboxchartgroups(CustomOpts, H)
0543 
0544    % Import each package member this local function requires.
0545    import groupstats.boxchartxdata
0546 
0547    if CustomOpts.ShadeGroups == false
0548       return
0549    end
0550 
0551    % Get the x-coordinate of the bounds of each boxchart group (the
0552    % left/right-most x-coordinate of each xtick group)
0553    [~, xleft, xright] = boxchartxdata(H);
0554 
0555    % Get the y-coordinate of the plot bounds, in the caller's axes
0556    ax = CustomOpts.Parent;
0557    [ylow, yhigh] = bounds(ylim(ax));
0558 
0559    % The x-tick grid is regular, so interpolate the NaN bounds. naninterp1
0560    % needs at least two known points to interpolate between, so a grid with
0561    % too few filled x-tick groups gets no shading rather than an error.
0562    if nnz(~isnan(xleft)) < 2 || nnz(~isnan(xright)) < 2
0563       return
0564    end
0565    xleft = naninterp1(1:numel(xleft),xleft,'linear','extrap');
0566    xright = naninterp1(1:numel(xright),xright,'linear','extrap');
0567 
0568    % To extend the shaded region halfway between each group:
0569    try
0570       dx = mean((xleft(2:end) - xright(1:end-1)),'omitnan') / 2;
0571    catch
0572       % Defensive catch for an unexpected indexing or arithmetic failure in
0573       % the gap computation; half the box width stands in for dx. The guard
0574       % above already returns when fewer than two bounds are known.
0575       dx = (xright - xleft) / 2;
0576    end
0577 
0578    xleft = xleft - dx;
0579    xright = xright + dx;
0580 
0581    idxodd = 1:2:numel(xleft);
0582    xpatch = [xleft(idxodd); xright(idxodd); xright(idxodd); xleft(idxodd); xleft(idxodd)];
0583    ypatch = repmat([ylow; ylow; yhigh; yhigh; ylow], 1, numel(idxodd));
0584 
0585    P = patch(ax, xpatch, ypatch, 'k', ...
0586       'FaceColor', [0.5 0.5 0.5], ...
0587       'FaceAlpha', 0.1, ...
0588       'EdgeColor', 'none' );
0589 
0590    % Set up a listener for changes in the YLim property
0591    addlistener(ax, 'YLim', 'PostSet', @(src, evt) updateshadedbounds(P, ax));
0592 
0593    function updateshadedbounds(P, ax)
0594       P.YData = repmat([ax.YLim(1); ax.YLim(1); ax.YLim(2); ax.YLim(2); ax.YLim(1)], ...
0595          1, size(P.Faces,1));
0596    end
0597 end

0599 function setboxchartylim(ax, H, XData, YData, CData)
0600    %SETBOXCHARTYLIM Fit the y limits to the whiskers when outliers are hidden.
0601    %
0602    % With MarkerStyle "none" boxchart draws no outlier points, so the visible
0603    % extent is the whisker tips. Fitting the limits to the plotted data
0604    % instead leaves empty space wherever an outlier was suppressed.
0605    %
0606    % The whiskers come from groupstats.boxchartydata, which computes them from
0607    % the data. Reading them off H(n).NodeChildren(4).VertexData instead
0608    % depends on undocumented graphics internals and needs a drawnow first.
0609 
0610    import groupstats.boxchartydata
0611 
0612    if ~all({H.MarkerStyle} == "none")
0613       return
0614    end
0615 
0616    % One box per pairing of an x-group member with a color-group member.
0617    xmembers = unique(XData);
0618    cmembers = unique(CData);
0619    whiskers = nan(numel(xmembers) * numel(cmembers), 2);
0620 
0621    k = 0;
0622    for x = 1:numel(xmembers)
0623       for c = 1:numel(cmembers)
0624          k = k + 1;
0625          inbox = XData == xmembers(x) & CData == cmembers(c);
0626          if any(inbox)
0627             whiskers(k, :) = boxchartydata(YData(inbox)).whiskers;
0628          end
0629       end
0630    end
0631 
0632    ywhiskers = whiskers(~isnan(whiskers));
0633    if isempty(ywhiskers)
0634       return
0635    end
0636 
0637    % Compute axis limits with padding. Pad by a fixed amount when every
0638    % whisker sits at the same value, because ylim rejects a zero-width range.
0639    bounds = [min(ywhiskers) max(ywhiskers)];
0640    padding = 0.01 * diff(bounds);
0641    if padding == 0
0642       padding = max(abs(bounds(1)), 1) * 0.01;
0643    end
0644    ylim(ax, bounds + [-padding padding]);
0645 end
